# 17 UI/UX Guidelines

## 1. Design Philosophy
The TrustLens AI Platform must be **Accessible, Authoritative, and Explainable**.
The client applications (Extension and Dashboard) are the only parts of the platform the user sees. The UI must cleanly abstract the complexity of the 10+ backend engines into simple, actionable insights generated by the Decision Engine.

## 2. Multi-Dimensional Score Displays
The UI must represent the distinct scores calculated by the Score Fusion Engine.

- **Primary Visualization:** A large circular progress gauge for the **Overall Trust Score**.
- **Secondary Gauges:** Smaller gauges or horizontal progress bars for **Security Score**, **Privacy Score**, and (if active) **Web3 Score**.
- **Confidence Indicator:** A small, textual or icon-based badge indicating the Confidence Score (e.g., "High Confidence", "Low Data").

## 3. Analysis Timeline
To build trust, the UI should visually demonstrate the thoroughness of the platform. Instead of a generic loading spinner, the extension should display a sequential timeline checklist:

1. `[x] Data Collected`
2. `[x] Features Extracted`
3. `[x] Threat Databases Queried`
4. `[x] Privacy Policy Analyzed`
5. `[x] Smart Contracts Audited` (Only shown if Web3 Engine active)
6. `[x] AI Analysis Complete`
7. `[x] Recommendation Generated`

## 4. Threat Categories & Explainability
- Use specific Threat Categories (e.g., "Credential Theft", "Tracking") rather than generic terms.
- Use Accordions to display the output of the **Explainability Engine**. Keep the initial view clean, allowing curious users to click to read the detailed human-readable AI translations.

## 5. Decision Engine Interventions (Colors)
The Decision Engine dictates the UI color scheme based on severity.
- **Safe (Low Severity):** Emerald Green
- **Warning (Medium Severity):** Amber/Yellow
- **Danger (High Severity):** Rose/Red (Triggers an active in-page overlay banner asking the user to leave the site).
